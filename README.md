# Script_Therion

Vous trouverez ici un ensemble de script pour hiérarchiser son travail avec Therion.

*create_survey_structure.py* permet de créer les dossiers pour démarrer réaliser le traitement d’une survey.

*run_all.py* est un script qu’il faut avoir dans un dossier parent à tout dossier de compilation. Il permet de lancer la compilation de l’ensemble des thconfig contenu dans les sous-dossiers
